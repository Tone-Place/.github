# Tone Place

Tone — социальная сеть и маркетплейс для дизайнеров интерьера. [tone.place](https://tone.place)

## Репозитории

- [`tone-backend`](https://github.com/Tone-Place/tone-backend) — Django API
- [`tone-frontend`](https://github.com/Tone-Place/tone-frontend) — веб (Next.js)
- [`tone-infra`](https://github.com/Tone-Place/tone-infra) — деплой и инфраструктура
- [`tone-place-react-native`](https://github.com/Tone-Place/tone-place-react-native) — мобильное приложение
- [`posts-app-django`](https://github.com/Tone-Place/posts-app-django), [`comments-app-django`](https://github.com/Tone-Place/comments-app-django), [`messaging-app-django`](https://github.com/Tone-Place/messaging-app-django) — сервисы бэкенда
- [`ui-tone-module`](https://github.com/Tone-Place/ui-tone-module) — дизайн-система мобильного приложения
